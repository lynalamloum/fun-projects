# Jeu du Pendu / Hangman Game
 
🇫🇷 Un petit jeu du pendu en Python que j'ai fait pour m'entraîner. On joue dans le terminal, c'est basique mais ça marche !
 
🇬🇧 A little Python hangman game I made to practice. You play in the terminal, nothing fancy but it works!
 
---
 
## Comment jouer / How to play
 
```bash
python pendu.py
```
 
🇫🇷 Le jeu choisit un mot au hasard (des termes d'informatique), et tu dois le deviner lettre par lettre. T'as 6 erreurs avant de perdre.
 
🇬🇧 The game picks a random word (computer science terms), and you guess it letter by letter. You get 6 mistakes before losing.
